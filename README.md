# Versun Music

Тёмный адаптивный музыкальный интерфейс с зелёными акцентами, поисковой панелью, локальными плейлистами, избранным и плеером.

## GitHub Pages
Этот репозиторий содержит статическую версию сайта. В Settings → Pages выбери Deploy from a branch, ветку main и папку /(root).

## Важно про Яндекс Музыку
GitHub Pages не запускает Python. Поэтому поиск по каталогу Яндекс Музыки и получение аудиопотоков требуют отдельного backend-сервера. В этой статической версии работают интерфейс, плейлисты и воспроизведение выбранных аудиофайлов с устройства. OAuth-токен не добавляй в публичный репозиторий.
